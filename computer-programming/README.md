# Computer Programming Tutorial

15-week introduction-to-programming curriculum (Python, AI-era pedagogy)
used in the *1306 100 Computer Programming* course at the Faculty of
Engineering, UBU.

Static HTML lecture pages (no build step). Open `index.html` in a browser,
or serve the folder with any static-file server.

## Live version

The canonical hosted version is on the [Mechatronics Engineering program
website](https://mechatronics-website-655397920844.asia-southeast1.run.app/tutorials).
This repo copy may lag slightly behind — see the umbrella README for the
website-vs-repo relationship.

## Contributing

Found a typo, broken link, or want to improve an explanation? Open a PR
against the relevant `.html` file. For minor fixes, GitHub's web editor is
fine — no local clone needed.
