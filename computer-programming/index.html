เรียนเขียนโปรแกรม
ยุค AI — ตั้งแต่ปัญหาจริง

คู่มือฉบับภาษาไทย ครอบคลุม 15 สัปดาห์ สำหรับนักศึกษาปี 1 วิศวกรรมศาสตร์ — เริ่มจาก "การมองเห็นปัญหาจริง" ก่อนเขียนโค้ดสักบรรทัด แล้วใช้ Python + AI เป็นเครื่องมือสร้างของจริงที่ใช้งานได้ — ไม่ใช่แค่ทำการบ้าน

📦 15 สัปดาห์ · 3 เฟส 🐍 Python 3 เป็นภาษาหลัก 🤖 ทำงานคู่ AI Agent 🎓 จบด้วย Project จริง

📋 ภาพสรุปหลักสูตร 15 สัปดาห์ในรูปเดียว — คลิกเพื่อดูขนาดใหญ่

หลักคิดของคู่มือนี้

ก่อน AI — เรียนเขียนโปรแกรม คือเรียน "แก้โจทย์ที่อาจารย์ให้" หลัง AI — เรียนเขียนโปรแกรม คือเรียน "หาโจทย์เอง แล้วสั่งให้ AI ช่วยทำ"

คู่มือนี้ไม่ได้สอน Python syntax ตามตำราเดิม แล้วค่อยพูดถึง AI ตอนท้าย — แต่ เริ่มจากพื้นฐานยุค AI ก่อน (สังเกตปัญหา · เขียน Diagram · เลือกเครื่องมือ) แล้วจึงเรียน Python เป็นเครื่องมือสำหรับทำสิ่งที่อยากทำให้สำเร็จ

เป้าหมายเมื่อจบ 15 สัปดาห์ นักศึกษาต้องสามารถ — มองเห็นปัญหา → อธิบายเป็น workflow → เขียน spec → สั่ง AI ช่วยสร้างต้นแบบ → ทดสอบของจริง → ปรับแก้ → ส่งมอบใช้งานได้กับเพื่อน 1 คน

เฟส 2 · Code Literacy with AI (W04–W07)

ไม่สอน Python syntax ทีละหัวข้อแบบเดิม — แต่ใช้ AI เป็น คู่หูฝึก เริ่มจาก อ่านโค้ดที่ AI เขียน ให้เข้าใจ → แก้ไข → สั่งงาน AI ครอบคลุม print/input/if/for/def ในเฟสเดียว

W04 · Literacy
อ่านโค้ดที่ AI เขียน
ติดตั้ง Python/Cursor · ขอ AI สร้างโปรแกรมเล็ก ๆ 3-4 ตัว แล้ว "อ่านให้เข้าใจ" ทั้ง print/input/if/for/def ในงานเดียว — ไม่ต้องท่อง syntax ก่อน
read Cursor trace
W05 · Literacy
แก้ไข + ต่อยอดโค้ด AI
แก้ AI's code ทีละนิด — เปลี่ยน condition, เพิ่ม field, ต่อ loop — เรียน syntax โดยลงมือ "แก้แล้วรัน" แทนการเรียนตามตำรา
edit syntax small steps
W06 · Literacy
สั่ง AI จาก Spec
เริ่มจาก spec ที่นักศึกษาเขียนเอง → AI สร้าง → นักศึกษาทดสอบ + แก้ — ฝึก "prompt อย่างชัดเจน" และ "ตรวจสอบงาน AI"
spec verify
W07 · Workshop
Workshop — 3 CLI Tools
สร้าง 3 เครื่องมือเล็ก ๆ ใน 1 สัปดาห์ — เครื่องคิดเลขเกรด · นับคำในไฟล์ · ตัวจัดการ TODO — ทำงานร่วมกับ AI ทุกขั้น
CLI end-to-end

class modules when-not-to
W12 · Advanced
APIs + Integration
