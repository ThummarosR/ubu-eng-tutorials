# PLC Automation Tutorial

Thai-language tutorial on PLC ladder-logic, FBD, HMI, PID, and Modbus
communication, covering both **Mitsubishi FX5U** and **Omron CP1L** families.

Static HTML — open `index.html` in a browser, or serve the folder with any
static-file server.

## What's covered

**Mitsubishi FX5U track:**
- Ladder-logic basics, contacts and coils
- Sensors and field wiring
- Simulation in GX Works3
- HMI (SK070FS) integration
- PID temperature control
- Modbus RTU communication

**Omron CP1L track:**
- Ladder-logic basics
- Function-block diagram (FBD)
- Modbus communication
- Temperature control with E5CC
- SCADA basics + workshop

## Reference manuals (not redistributed)

The tutorial references vendor manuals for full instruction-set details.
Download the relevant ones from the vendor:

- **Mitsubishi FX5U User's Manual** — https://www.mitsubishielectric.com/fa/download/
- **Omron CP1L Operation Manual (W462)** — https://www.ia.omron.com/products/
- **Delta DTB / DTK Temperature Controller** — https://downloadcenter.deltaww.com/

These are the vendor's copyrighted documents and are not included here.
